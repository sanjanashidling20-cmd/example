PYTHON DEBUGGING PRACTICE
=========================

Project Name:
Student Marks Program

Description:
This is a simple Python program created for debugging practice.
The program asks the user to enter a student's name and marks in
three subjects. It calculates the total and average marks and displays
whether the student has passed or failed.

Purpose:
The purpose of this project is to practise finding and correcting
common Python errors.

Errors included in the practice code:
1. Division by zero.
2. Missing colon after an if statement.
3. Missing colon after an else statement.
4. Incorrect variable name.

How to Run:
1. Install Python on your computer.
2. Download or clone this GitHub repository.
3. Open the project folder in VS Code or another Python editor.
4. Run the Python file using:

   python student_marks.py

Note:
The original Python file intentionally contains errors.
Correct the errors before running the program successfully.
